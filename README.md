
# Public Transport Tracker

Real-time public transport tracking system built for SIH (Smart India Hackathon).

## Overview

This project provides real-time tracking and monitoring of public transportation systems, helping users track vehicle locations, schedules, and routes efficiently.

## Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: JavaScript, EJS, Tailwind CSS, Bootstrap
- **Database**: MongoDB
- **API**: RESTful APIs
- **Testing**: Postman
- **Deployment**: Netlify, Render

## Getting Started

### Prerequisites

- Node.js installed
- MongoDB database
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Vikas05113/public-transport-tracker.git
cd public-transport-tracker
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env
# Configure your database and API keys in .env
```

4. Start the development server:
```bash
npm start
```
